# 女儿的视频相册

手机视频相册，支持浏览、主题筛选、点播、前后切换、随机播放、分享，以及任何访客上传视频并自动公开展示。

## 发布

在 GitHub 创建仓库，将本目录的全部文件（含 media 文件夹）上传至 main 分支根目录。进入 Settings → Pages，选择 Deploy from a branch，选 main 和 /(root)。

公开仓库里的页面、视频和封面均可被任何人查看和下载。页面设置 noindex 以请求搜索引擎不收录，但这不构成访问控制。

## 本次内容

包含用户提供的 14 段视频及对应封面。标题按画面暂拟，可以继续修改。原文件夹保持不变。

## 检查

已在本地 Chrome 手机模拟视口逐段检查全部 14 段视频解码及播放。已检查分类、单段直达链接、关闭播放器和无横向溢出。布局检查覆盖 1440、768、390 像素。尚未在实体手机或微信内置浏览器验收。

视频与图片的权利属于各自权利人。本仓库不授予视频、肖像或其他素材的再利用许可。

## 访客上传

前端：GitHub Pages。上传服务：https://little-moments-7k3p9.largewolf.chatgpt.site 。后端通过 Cloudflare D1 保存列表，R2 保存视频与封面。新增视频不会写入 GitHub 仓库，上传后直接出现在相册。

MP4、MOV、WebM，单个最大 200 MB、时长不超过 1 小时；手机浏览器必须能读取该视频。每个文件按 5 MB 分段上传，网络错误自动重试当前段，提供进度和取消功能。上传完成后才公开展示。当前页面立即更新，其他可见页面每 15 秒自动同步，切回页面也会同步。

已公开允许匿名上传，上传的视频对全部访客可见。每个网络来源每小时最多发起 20 次上传。不要在前端加入 GitHub 凭证或后端管理密钥。上传会话凭证仅授予该次上传，1 小时有效。
