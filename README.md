# 女儿的视频相册

面向手机的静态视频相册，支持主题筛选、点播、分类内前后切换、随机播放和单段链接分享。包含14段视频及对应封面。

## 播放

- 选择主题后，上一段、下一段和随机播放均限定在该主题；在“全部”中可以浏览所有视频。
- “音乐”分类包含《风里的小暖阳》（1:00）和《掌心的小星光》（2:21）。音乐默认列表循环，也可选择单曲循环或播完停止。音乐自动续播始终限定在音乐分类。
- 分享的单段链接打开后等待用户点击播放；后续切换限定在该视频所属分类。
- 加载时显示提示，加载失败或等待20秒后提供重新加载和直接打开视频。重试尝试恢复当前播放位置。
- 自动播放仍遵循浏览器限制；浏览器要求用户操作时会提示点击播放。

## 上传暂停

上传入口保持隐藏，页面已移除上传和远程列表同步脚本，不再轮询后台、切回页面同步或发起上传服务请求。当前视频、封面均由 GitHub Pages 提供。未来恢复上传时需重新接入可用后端。

## 发布

仓库 main 分支通过 GitHub Pages 发布，页面入口为 index.html，视频位于 media/。修改脚本、样式时更新 HTML 中的资源版本号，以减少旧缓存影响。

公开仓库中的页面、视频和封面均可被任何人查看和下载。noindex 是请求搜索引擎不收录，不构成访问控制。视频与图片的权利属于各自权利人，本仓库不授予视频、肖像或其他素材的再利用许可。

## 验证范围

已用媒体事件逻辑检查四个分类的前后切换、三种音乐播放模式、加载超时与失败重试及请求停用，并在浏览器检查手机播放界面。实体手机和微信内置浏览器仍需实际使用验证。

## 无损加载优化

- 12 段短视频仅用 stream copy 前置 MP4 索引，没有重新编码。处理前后逐条音视频流的 SHA-256 一致；两段音乐原本已前置索引，未改动。生成脚本：`python3 scripts/faststart.py /path/to/ffmpeg`。
- 默认仍直接播放。打开视频后可点“完整加载后播放（原画质）”，显示下载进度；完整下载原视频后，通过内存 Blob 播放，保留当前位置。浏览器阻止自动播放时，点击播放即可。
- 可取消加载或切回直接播放。30 秒无下载进展会提示重试；切换视频、关闭播放器会取消当前下载并释放内存。只缓存当前视频，不跨视频或页面持久保存；下一段仍默认直接播放。
- 已验证真实 Blob 视频加载、失败重试、进度、取消、切换与关闭清理、过期响应隔离，以及手机横竖屏布局。微信实体手机仍需验收，本次未发布。
