# 女儿的视频相册

静态视频相册，支持手机浏览、主题筛选、点击播放、前后切换、随机播放、相册分享和单段视频链接。

## 发布

在 GitHub 创建仓库，将本目录的全部文件（含 media 文件夹）上传至 main 分支根目录。进入 Settings → Pages，选择 Deploy from a branch，选 main 和 /(root)。

公开仓库里的页面、视频和封面均可被任何人查看和下载。页面设置 noindex 以请求搜索引擎不收录，但这不构成访问控制。
